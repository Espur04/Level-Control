# Level Control

## EN

**Level Control** lets you choose the physical level prefab used by an individual growable building in *Cities: Skylines II*. It supports residential, mixed-use, commercial, industrial, and office buildings when a compatible prefab exists for the building's zone and footprint.

Select a building and open the **Level Control** panel. The level buttons show the levels available for that building. Choosing one schedules the building's replacement with a prefab at the selected level, so its model and prefab data match the chosen level. Requests made while the simulation is paused appear in the panel immediately and are processed when simulation resumes.

Use the lock button to prevent a building from leveling up automatically. In mod settings, **Lock all buildings** applies the lock to existing buildings. **Lock level when placed** automatically locks newly placed growable buildings. These settings are stored with the game's mod settings; building levels and individual locks are stored with the city.

Level Control only offers prefabs compatible with the selected building. A level may be unavailable when the game has no matching prefab for that building's zone, footprint, access, or properties.

## FR

**Level Control** permet de choisir le prefab physique de niveau utilisé par un bâtiment zonable dans *Cities: Skylines II*. Le mod prend en charge les bâtiments résidentiels, mixtes, commerciaux, industriels et de bureaux lorsqu'un prefab compatible avec la zone et l'emplacement du bâtiment existe.

Sélectionnez un bâtiment et ouvrez le panneau **Level Control**. Les boutons indiquent les niveaux disponibles pour ce bâtiment. Le choix d'un niveau programme son remplacement par un prefab de ce niveau : son modèle et ses données correspondent donc au niveau choisi. Les actions effectuées lorsque la simulation est en pause s'affichent immédiatement dans le panneau, puis sont appliquées à la reprise.

Le cadenas empêche un bâtiment de monter automatiquement de niveau. Dans les paramètres du mod, **Verrouiller tous les bâtiments** applique le verrouillage aux bâtiments existants. **Verrouiller le niveau à la pose** verrouille automatiquement les nouveaux bâtiments zonables. Ces paramètres sont enregistrés dans les paramètres du mod du jeu ; le niveau et le verrouillage de chaque bâtiment sont enregistrés avec la ville.

Level Control ne propose que les prefabs compatibles avec le bâtiment sélectionné. Un niveau peut être indisponible si le jeu ne possède aucun prefab correspondant à sa zone, son emplacement, son accès ou ses propriétés.
